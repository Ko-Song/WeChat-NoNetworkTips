# WeChat-NoNetworkTips
基于 Xposed 框架的微信断网提示与横幅净化模块。
## 功能说明
* **断网横幅清除**：移除微信主界面的“当前无法连接网络”置顶横幅及残留空白底板。
* **全局 Toast 拦截**：无差别拦截微信的断网及相关提示弹窗，并在日志中输出原始内容。
## 使用方法
1. 进入本仓库的 **Actions** 页面，点击最近一次成功构建的工作流（Workflow）。
2. 在页面底部的 **Artifacts** 区域下载构建产物，解压后安装 APK 文件。
3. 在 LSPosed 管理器中启用模块，并将作用域勾选为微信 (`com.tencent.mm`)。
4. 强行停止微信后重新打开。
